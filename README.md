# Edge Clipboard

Компактная панель буфера обмена для Windows 10/11 x64.

Сохраняет три последних текста и три изображения. Открывается при наведении на тонкую полоску у края экрана. Нажатие копирует элемент для обычной вставки через Ctrl+V. Файлы и папки игнорируются, ссылки копируются как текст.

## Установка

[Скачайте установщик Edge Clipboard](https://github.com/Slavabond13/edge-clipboard-releases/releases/latest/download/Slavabond13.EdgeClipboard-win-Setup.exe) и запустите его. Установка выполняется для текущего пользователя. На рабочем столе и в меню «Пуск» появится Edge Clipboard. Все выпуски доступны на [странице релизов](https://github.com/Slavabond13/edge-clipboard-releases/releases).

Правой кнопкой по полоске или значку возле часов открываются настройки: край экрана, положение, монитор, размер, очистка истории и выход.

## Обновления

Установленная программа проверяет новые версии при запуске и затем раз в сутки. Обновления скачиваются в фоне и применяются при следующем запуске. В меню **«Обновления»** доступны ручная проверка, отключение автоматического скачивания и **«Перезапустить и обновить»**.

## Данные

История и настройки находятся на вашем компьютере в `%LOCALAPPDATA%\Slavabond13\EdgeClipboard`. История зашифрована Windows DPAPI и привязана к учётной записи Windows. Эти файлы не входят в установщик и не отправляются на GitHub. Обновление программы сохраняет их. Автозагрузка Windows не включается.

Исходный код проекта хранится отдельно в закрытом репозитории. Этот публичный репозиторий содержит только описание и готовые выпуски программы. Приложение использует Velopack и Newtonsoft.Json; сведения об их лицензиях включены в пакет.
